# OknaServiceAndroidApp

Приложение для компании "Окна Сервис", занимающейся производством, доставкой и установкой пластиковых окон.
Функционал дополненной реальности используется для получения приблизительных значений ширины и высоты окна для расчета предварительной стоимости.
